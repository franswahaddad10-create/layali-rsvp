# Layali RSVP deployment

The repository is prepared for a free deployment using:

- **Frontend:** Vercel, using the repository root and `vercel.json`.
- **Backend:** Render Web Service, using the `backend` directory and `render.yaml`.
- **Database:** MongoDB Atlas free cluster.

## Vercel environment variable

Set this variable in the Vercel project settings:

```text
REACT_APP_API_URL=https://<render-service>.onrender.com/api
```

The value must end with `/api` because the frontend client appends route paths such as `/auth/login`.

## Render required values

The Render Blueprint requests these values securely during setup:

- `MONGODB_URI`: MongoDB Atlas connection string, with a database name such as `layali_rsvp`.
- `ADMIN_USERNAME`: a non-default production username.
- `ADMIN_PASSWORD`: at least 10 characters, including uppercase, lowercase, and a number.
- `ALLOWED_ORIGINS`: the exact Vercel URL, for example `https://layali-rsvp.vercel.app`.
- `APP_URL`: the exact public Vercel URL.

`JWT_SECRET` is generated by Render. WhatsApp provider configuration is set to `manual`; manual invitation links do not require paid Twilio or Meta credentials. Paid WhatsApp API credentials can be added later through Render environment variables if desired.

## Deployment order

1. Create the MongoDB Atlas free cluster and allow the Render service to connect.
2. Deploy the backend from the repository with the Render Blueprint. Copy the resulting `onrender.com` URL.
3. Create the Vercel project from the same repository and set `REACT_APP_API_URL` to the Render URL plus `/api`.
4. Update Render `ALLOWED_ORIGINS` and `APP_URL` with the final Vercel URL, then redeploy the backend.
5. Verify `https://<render-service>.onrender.com/api/health` and the frontend login flow.

Never commit `.env` files, MongoDB credentials, JWT secrets, or WhatsApp tokens.
